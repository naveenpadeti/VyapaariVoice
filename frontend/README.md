# VyapaariVoice Frontend Application

React 18 + Vite 6 + Tailwind CSS dashboard and voice interface for Indian wholesale and retail shops.

## Features
- **Dashboard**: High-level inventory KPI cards, Recharts sales trends, top-selling bar charts, low-stock alerts
- **Stock Inventory**: Filterable table by category & status, quick +Add and -Remove stock buttons
- **Product Catalog**: Full product details, unit configuration, reorder & target thresholds, CRUD modal
- **Product Details & Intelligence**: Real-time stock, 30-day velocity, coverage days, and deterministic refill recommendation
- **Categories**: Manage product groups and commodities
- **Transactions**: Complete ledger of movements with source badges (MANUAL, VOICE, SYSTEM)
- **Low-Stock Alerts**: Urgency badges (Critical, High, Medium), suggested refill quantities, and 1-click refill
- **Voice Assistant**: Interactive microphone with animation, live transcription, audio replay, structured inventory cards, and prompt suggestions in Telugu, Hindi, English
- **Global Voice Button**: Floating `🎤 Ask VyapaariVoice` button on all dashboard pages

## Build & Run Locally
```bash
npm install
npm run dev
```
Access at: `http://localhost:5173`
